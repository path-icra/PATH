# Project page

Static project page for an anonymous conference submission.
Content lives in `template.yaml`; media goes in `public/`.

```bash
npm install
npm run dev     # http://localhost:8080
npm run build   # outputs to build/
```

Built on the [Academic Project Page Template](https://github.com/denkiwakame/academic-project-template)
